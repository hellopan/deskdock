# DeskDock 1.4.6

## 更新内容

- 使用 iOS Liquid Glass 风格的深浅主题、玻璃工具栏与控件反馈。
- 设置页签移至左侧，移除重复标题和常驻解释文案。
- 设置窗口默认高度调整为 920px，并保持在主窗口上方。
- 主窗口与设置窗口统一使用 28px 外圆角。
- 每排图标个数支持 4–20；屏幕空间不足时自动减少实际列数。
- 四个停靠方向共用可调面板高度，默认 780px，支持 220–1200px。
- “关于”页新增 GitHub 项目链接。
- 改善快速切页、连续折叠、弹窗重入、键盘导航及减少动态效果的行为。

## 安装

下载 `DeskDock_Setup_1.4.6.exe` 后安装，支持 Windows 10 / 11 x64。
覆盖安装保留已有配置和快捷方式数据。

## 验证

已验证 920px 窗口高度、圆角一致性、GitHub 链接、20 列配置保存、四向停靠高度、
侧栏键盘导航、弹窗重入和减少动态效果；构建后校验安装包与更新元数据。
