# 桌面坞 DeskDock

把桌面上散落的软件快捷方式收进一个贴在屏幕边缘的小坞里，鼠标滑到边缘自动呼出、离开自动收起。
桌面从此干干净净，但打开软件比以前更快。

Windows 10 / 11（x64）

---

## 功能

**一键收纳**
点击右上角 ↓ 扫描桌面（含公共桌面）的全部 `.lnk` / `.url`，勾选后导入。
文件会先完整复制到应用数据目录，确认副本无误后才移除桌面上的原件 —— 不是删除，随时可复原。
坞里已有同名条目（之前配置过分类）时会保留原分类、不重复添加，只有新条目才放进所选分类；
这一行为由「已配置过分类的快捷方式，仍放回原分类」勾选控制（默认开，设置会被记住）。

**贴边隐藏**
坞贴在屏幕左侧（可改右/上/下），停靠时只留 4px 感应条；鼠标滑到屏幕边缘立即滑出，
移开后延时收起。点顶栏的图钉可以固定常显。

**拖动换向**
顶栏按住拖动时，坞会沿当前这条边滑动；把光标拖到另一条边附近（约 120px 内），
坞会自动换方向吸附过去 —— 比如从右边一路拖到屏幕顶部，松手就变成贴顶的横向坞。
换向时坞会以光标为中心自动居中到新边上，松手才写盘。

**宽度自适应**
贴左/右边时，每排最多 10 个图标，超出的自动换到下一排；
坞的宽度按"所有分类里图标最多的那一组"自动计算 —— 最多的一组只有 5 个，坞就只有 5 个图标宽，不会留一大片空白。
贴上/下边时，坞的宽度固定为屏幕宽度的 80%，图标按可用宽度自动换行。

**分类管理**
默认六个分类：编程开发 / 聊天社交 / 影音娱乐 / 游戏 / 办公工具 / 未分类。
- 新建分类、右键分类头可重命名、换颜色、删除（分类里的图标会转到其他分类，不会丢）
- 分类左侧的 ⠿ 手柄拖动可给分类排序，点分类头可折叠

**拖拽整理**
图标可以直接拖到别的分类里，也能在分类内部拖到指定位置；
从资源管理器把 `.lnk` 拖进窗口，会加到鼠标停留的那个分类。

**设置**
点坞右上角的滑杆图标打开独立的设置窗口，坞会留在原地保持展开，改尺寸、主题、列数能当场看到效果；
关掉设置窗口后，坞恢复原来的自动隐藏。设置分四页：外观（主题/图标/磁贴/每排个数/冷却）、
行为（贴边、显示与隐藏、开机自启）、数据（目录、备份恢复、修复失效、清空）、关于。

**其他**
搜索（Ctrl+F）、托盘常驻、右键图标可「打开 / 打开文件所在位置 / 重命名 / 移动到分类 / 移出坞」。

## 运行与打包

```bash
npm install          # 安装依赖
npm start            # 开发模式运行
npm run icon         # 重新生成图标（build/icon.png、build/icon.ico）
npm run dist         # 打包成安装程序 → dist/
```

打包产物：`dist/DeskDock Setup 1.1.3.exe`（NSIS 安装包，可选安装目录，装完会有桌面和开始菜单快捷方式）。

> 国内网络下载 Electron 慢的话，加上镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`

## 数据存放位置

v1.1.3 起放在**用户数据目录**，和安装目录彻底解耦 —— 覆盖升级、重装、卸载都不会动它：

```
%APPDATA%\DeskDock\DeskDockData\
    config.json         分类、条目索引、全部设置
    shortcuts\          所有快捷方式实体文件（.lnk / .url）
    backup\             config.json 的历史快照（自动，最多 40 份）
```

- 开发模式下是 `<项目目录>\DeskDockData\`
- 安装版是 `%APPDATA%\DeskDock\DeskDockData\`
- 绿色版：在 exe 旁边放一个空的 `DeskDockPortable.txt`，数据就留在安装目录（随 U 盘走）
- 老版本升级时，会自动把安装目录里的 `DeskDockData` 复制到新位置（源目录保留不删）
- 设置 → 数据：可直接打开数据目录 / 快捷方式文件夹 / 备份文件夹

> **为什么改位置**：v1.1.2 及以前数据放在 `<安装目录>\DeskDockData`，而 electron-builder 的
> NSIS 卸载器在"覆盖安装"时会把整个 `$INSTDIR` 搬到临时目录再删掉，用户数据跟着一起没了。
> v1.1.3 除了换位置，还加了 `build/installer.nsh` 接管卸载时的删文件逻辑，
> 让"装在安装目录里的旧数据"在升级/卸载时也能保住。

**关于"不丢快捷方式"**：

- 导入 = 复制到 `shortcuts\` → 校验大小一致 → 把桌面原件丢进**回收站**（不是直接删除，误删可捞回）
- 每次改动前自动给 `config.json` 拍快照，设置 → 数据安全 里可一键备份 / 从任意快照恢复
- 条目指向的文件丢失时**不会再被静默删掉**：仍保留在列表里（灰态带 `!` 角标），
  并会用记录下的 `target` 自动重建 `.lnk`；config.json 彻底丢了也会按 `shortcuts\` 里的文件名自愈重建索引

## 图标是怎么取的

直接对 `.lnk` 取图标只能拿到「通用快捷方式」那张白纸图标；而有些 Electron 应用
（DeepSeek Harness、MINI Coder、OpenCode 这类）连 exe 走 Windows Shell 都只能拿到
「未知程序」图标。所以按下面的顺序取，并且**同时尝试多个来源、保留最清晰的那张**：

1. `.lnk` 里写的 `IconLocation`（用户自定义图标的快捷方式靠它，安装器的 `ProductIcon` 也算）
2. `.lnk` 的真实目标 exe —— 用一次 PowerShell 批量解析出目标，再**自己解析 PE 资源**
   （`RT_GROUP_ICON` / `RT_ICON`），通常能拿到 256×256 原图，比 Shell 的 32×32 清楚得多
3. `.url` 里写的 `IconFile=`（Steam 游戏快捷方式就靠这个）
4. 都取不到 → 交给 Windows Shell 兜底

PE 解析只读文件头和资源段（十毫秒级），不会把几百 MB 的 exe 整个读进内存。
目标解析是异步的：刚导入的一两秒内可能还是白纸图标，解析完成后会自动刷新成真图标。

## 开机自启

设置 → 启动 → 开机自启。底层用 `app.setLoginItemSettings` 写入当前用户的启动项，
以 `--hidden` 参数静默启动（只在托盘待命，不弹面板）。开发模式下不可用，打包安装后生效。

## 结构

```
src/
  main/
    main.js      窗口、贴边感应与自动隐藏、托盘、开机自启、IPC、右键菜单
    store.js     config.json 读写、分类/条目增删改、桌面扫描与导入
    winicon.js   批量解析 .lnk 目标/IconLocation + 挑选最清晰的图标
    peicon.js    解析 exe 的 PE 资源，直接把图标抠出来（只读资源段）
  preload/
    preload.js   contextBridge 白名单 API
  renderer/
    index.html   坞面板骨架
    settings.html 设置窗口骨架（独立 BrowserWindow）
    tokens.css   设计令牌（颜色/字号/间距/圆角/动效的唯一来源）
    styles.css   坞面板样式（深/浅两套主题）
    settings.css 设置窗口样式
    icons.js     JS 动态注入的 SVG 图标常量
    renderer.js  列表渲染、拖拽、弹窗
    settings.js  设置窗口的四页签逻辑
scripts/
  gen-icon.js      纯 Node 生成 PNG/ICO 图标（零依赖）
  preview-shot.js  开发用：假数据渲染截图
  settings-shot.js 开发用：独立设置窗口截图与联动断言
  verify-ui.js     开发用：上下贴边/拖拽跨分类/跨屏换边/浅色真实图标/roving 断言
  screen-shot.js   开发用：抓整屏（含贴边窗口）
build/             应用图标
```

界面的取值规则与验收方式见 `DESIGN.md`。

## 小提示

- 呼不出？确认坞没有被其他全屏程序（游戏/播放器）遮挡，全屏独占模式下 Windows 不会让浮层显示；
  也可以点托盘图标直接呼出。
- 图标空白？说明快捷方式指向的程序已被移动/卸载。右键「打开文件所在位置」可以确认。
- 想换电脑？把整个 `DeskDockData` 目录复制过去即可，分类和图标都在里面。
